Mode simulation — pas d’ESP32. Le TVM n’est pas commandé par cette page.

Enregistrement : arrêté. Colonnes CSV : time_ms,force_N,force_kg,event. Pas d’extensomètre sur l’ESP32.

Le mouvement est assuré par le mode Repeat du TVM. L’ESP32 ne commande pas le vérin : il mesure la force et compte les cycles à partir des pics. Pas de capteur de déplacement.

Dernier cycle : Fmin — · Fmax —. CSV : cycle,t_ms,Fmin_N,Fmax_N.

Cellule CZL301 500 kg, 2,0030 mV/V, 350 Ω, 0,02 % FS. Excitation HX711 à 3,3 V (GPIO ESP32 non 5 V tolerant). Surcharge constructeur 120 % FS. Limite logicielle par défaut 4000 N, plafond dur < 4900 N.

Relais STOP : GPIO 26, actif haut (HIGH = relais collé = coupure moteur). Pilotage via transistor, jamais la bobine en direct. Inverser STOP_ACTIVE_HIGH dans config.h si le câblage est actif bas.
